# Coding Standards (FrontendForge)

> **Scope note:** This file lives under `AI/FrontendForge/Rules/`, so VS Code does **not** auto-load it as a workspace instruction (only files in `.github/instructions/` are auto-applied). It is referenced on purpose by the starter agent. The `applyTo` above is intentionally narrow so that, if you ever copy it into `.github/instructions/`, it only touches generated project source — never the rest of the StudyNote workspace.

## TypeScript
- `strict: true`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- No `any`; use `unknown` + narrowing. Model states with **discriminated unions**.
- Prefer `type` for unions, `interface` for object contracts.
- Validate all external data at boundaries with **Zod** (API responses, forms, env).

## Files & structure
- Feature-sliced: `features/<name>/{ui,model,api,index.ts}`. Import slices only via `index.ts`.
- One component per file; colocate its test (`*.test.tsx`) and styles.
- Named exports preferred over default exports (except framework-required entry points).

## Components
- Keep components pure and small; extract logic into hooks.
- Explicit prop types; no prop drilling beyond 2 levels (use context/store).
- Handle every state: default / loading / empty / error / success.

## Naming
- Components `PascalCase`, hooks `useCamelCase`, vars/functions `camelCase`, constants `SCREAMING_SNAKE_CASE`, files match export.

## Imports
- Order: node builtins → external → internal aliases (`@/…`) → relative. Enforce with ESLint import order.

## Styling
- Use the design tokens from `05-UIUX-Design.md`; never hard-code colors/spacing.
- Logical CSS properties for RTL support.

## Errors & logging
- No swallowed errors; use error boundaries + typed error objects.
- No `console.log` in committed code (allow a structured logger).

## Lint / format
- ESLint flat config + `typescript-eslint` + Prettier. CI fails on lint/type errors.

## Git
- **Conventional Commits** (`feat:`, `fix:`, `chore:`…). Trunk-based with short-lived branches.
- PR checklist: tests added, coverage ≥ 90%, a11y checked, no secrets, docs updated.

## Security
- Never store tokens in `localStorage`. No secrets in the bundle. Sanitize any HTML injection.
