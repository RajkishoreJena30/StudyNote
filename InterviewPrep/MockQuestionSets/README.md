## How to Run a Self-Mock

1. **Pick a tier** you're targeting this week.
2. **Set a timer** for each round (times are listed in every file).
3. **Answer out loud** as if an interviewer is present — record yourself if you can.
4. **Self-grade** each round using the ⭐ signals at the end of each section.
5. **Fill the Post-Mock Scorecard** at the bottom of each file.
6. **Any round ≤ 3/5 → drill it** before your next mock.

## Suggested Order (warm-up → dream)

Aligns with §9 of the main guide — start easier tiers as live mocks, then escalate:

1. **Tier 4 (Volume service)** — warm up, rebuild fundamentals + project story.
2. **Tier 3 (Premium service)** — practice communication + clean-code pairing.
3. **Tier 2 (Mid product)** — machine coding + React depth under pressure.
4. **Tier 5 (GCC)** — DSA + system design at a product bar.
5. **Tier 1 (Product/unicorn)** — your dream targets, once Phases 3–6 are solid.
