# Tier 4 — Service (Volume) — Full Mock Interview Question Set

> **Companies (type):** TCS, Infosys, Wipro, Cognizant, Accenture
> **What they weigh most:** Fundamentals + project depth + framework basics
> **CTC band (Sr, 5–6y):** ₹12–22 LPA
> **How to use:** Timer per round, answer out loud. This tier weighs **breadth of fundamentals, project explanation, and framework basics**. Depth of trivia matters; polish your project story.

---

## Round 0 — HR / Screening Call (15–20 min)

1. Brief introduction and total years of experience.
2. Current CTC, expected CTC, notice period.
3. Which technologies are you strongest in?
4. Are you open to the client location / onsite / rotational shifts?
5. Reason for change.
6. Highest qualification & certifications.

**⭐ Self-grade:** Clear, polite, straightforward answers; correct comp + notice details.

---

## Round 1 — Technical Screen: Fundamentals (45–60 min)

### HTML
1. Semantic HTML elements and why they matter.
2. `block` vs `inline` vs `inline-block`.
3. Difference between `id` and `class`.
4. Forms, input types, validation attributes.
5. What are data attributes?
6. Meta tags & basic SEO.

### CSS
7. Box model.
8. `position`: static/relative/absolute/fixed/sticky.
9. Flexbox vs Grid — when to use each.
10. Specificity — how it's calculated.
11. Ways to center a div.
12. `rem` vs `em` vs `px` vs `%` vs `vh/vw`.
13. Pseudo-classes vs pseudo-elements.
14. Media queries / responsive design.

### JavaScript
15. `var` vs `let` vs `const`.
16. `==` vs `===`.
17. Closures (with example).
18. Hoisting.
19. `this` keyword.
20. Arrow vs regular functions.
21. `map` vs `forEach` vs `filter` vs `reduce`.
22. Promises vs callbacks vs async/await.
23. `null` vs `undefined`.
24. Event bubbling & delegation.
25. Shallow vs deep copy.

**⭐ Self-grade:** Broad, accurate fundamentals; concise definitions with a quick example each.

## Round 2 — React / Framework Basics (45 min)

1. What is the Virtual DOM?
2. Class vs functional components.
3. `useState`, `useEffect` — basic usage and dependency array.
4. Props vs state.
5. Lifting state up.
6. Controlled vs uncontrolled components.
7. What are keys in lists and why needed?
8. `useRef`, `useMemo`, `useCallback` — basic purpose.
9. Context API — what and when.
10. React Router basics — routes, params, navigation.
11. How do you call an API in React? (`useEffect` + fetch/axios).
12. Redux basics — store, actions, reducers, dispatch (or Redux Toolkit).
13. Component lifecycle (mount/update/unmount).
14. Handling forms and events.

**⭐ Self-grade:** Solid framework basics, correct hook usage, can explain data flow clearly.

### Optional — Light Hands-On (10–20 min)

*Not a full machine-coding round at this tier, but a short live task may be folded in here. Practice these so you're not caught off guard.*

1. Build a **controlled search input** that filters a static list as you type.
2. **Fetch and render a list** from an API with loading and error states (`useEffect` + fetch/axios).
3. Build a **counter or mini todo** — add, toggle/complete, delete.
4. **Fix a broken snippet** — e.g., a `useEffect` infinite loop (missing/incorrect dependency array) or a stale-state bug.

**⭐ Self-grade:** Working component under time, correct hook usage (deps + cleanup), handled loading/error, readable code while narrating.

## Round 3 — Coding / DSA (Basic to Medium) (45 min)

1. Reverse a string / check palindrome.
2. FizzBuzz.
3. Find largest/second largest in an array.
4. Remove duplicates from an array.
5. Count character/word frequency in a string.
6. Fibonacci (iterative + recursive).
7. Check for anagram.
8. Sort an array (and know built-in sort behavior).
9. Find missing number in 1..n.
10. Simple object/array manipulation (group, flatten).
11. Two Sum.
12. Basic recursion (factorial, sum of digits).

**⭐ Self-grade:** Correct working solutions, can explain logic, aware of basic complexity.

## Round 4 — Project Deep-Dive (45–60 min) ⭐ heavily weighted

*This tier interrogates your project story in depth. Prepare it thoroughly.*

1. Explain your current/last project — architecture, your role, tech stack.
2. What was the most challenging feature you built? How?
3. How is state managed in your project?
4. How do you handle API integration and errors?
5. How did your team handle version control / branching / releases?
6. How did you test your code?
7. What was your team size and your responsibilities?
8. A bug you fixed that was hard to trace.
9. How did you handle performance issues?
10. Agile/Scrum process on your project — your involvement.

**⭐ Self-grade:** Confident end-to-end project narrative, clear personal contribution, honest technical depth.

2. REST API principles.
3. What is CORS?
4. Cookies vs localStorage vs sessionStorage.
5. Authentication basics — JWT, sessions.
6. Git basics — merge vs rebase, resolving conflicts.

## Round 6 — Managerial / Behavioral (30–45 min)

1. Walk me through your career and growth.
2. How do you handle tight deadlines?
3. A conflict in your team and how you resolved it.
4. How do you handle feedback?
5. Have you mentored juniors?
6. Why do you want to leave your current company?
7. Why our company?
8. Are you comfortable with the client's shift timings / location?
9. Where do you see yourself in 3–5 years?

**⭐ Self-grade:** Professional, stable, team-oriented answers; clear motivation.

---

## Round 7 — HR / Salary Negotiation (20–30 min)

1. Current CTC breakdown (fixed + variable).
2. Expected CTC.
3. Notice period & buyout options.
4. Any competing offers?
5. Flexibility on location / shift / onsite.

**Playbook:**
- Volume-service bands (₹12–22 LPA) are structured — negotiate on **hike % over current** (aim 30–50%+ with a switch).
- Have a competing offer if possible — biggest lever here.
- Clarify designation/band mapping, appraisal cycle, variable payout history.
- Get the offer + join date in writing; confirm buyout policy.

**⭐ Self-grade:** Negotiated a strong hike %, used competing offer, clarified band + variable.
