## 1. TypeScript
- `strict: true`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- **No `any`** — use `unknown` + narrowing. Model async/UI states as **discriminated unions** (see `useAiStream`).
- `type` for unions, `interface` for object contracts. Exhaustive `switch` with `never` default.
- Validate **all** external data at boundaries with **Zod** (API, forms, env, SSE payloads).

## 2. Structure & boundaries
- Feature-sliced per app: `features/<name>/{ui,model,api,index.ts}`; import a slice only via its `index.ts`.
- **Remotes never import each other** — communicate via the shell router or the typed `event-bus`. Enforced by `eslint-plugin-boundaries`.
- Shared code lives in `packages/*`; apps never reach into another app.
- One component per file; colocate `*.test.tsx`.

## 3. Components & state
- Keep components pure and small; push logic into hooks.
- Explicit prop types; no prop drilling beyond 2 levels (context/store).
- Handle every state: default / loading / empty / error / success.
- Server state → TanStack Query; client global → Zustand; **never put server state in the global store**.

## 4. Naming & imports
- Components `PascalCase`, hooks `useCamelCase`, vars/functions `camelCase`, constants `SCREAMING_SNAKE_CASE`; filenames match the export.
- Import order: node builtins → external → `@nexusdesk/*` packages → `@/` app aliases → relative. Named exports preferred.

## 5. Styling
- Use **design tokens** from `packages/tokens` (generated by **Style Dictionary** from Figma variables); never hard-code colors/spacing.
- **Logical CSS properties** only (RTL-safe). Variants via CVA.
- Gate optional / plan-tier UI behind **OpenFeature** flags — never by commenting out code.

## 6. Errors & logging
- No swallowed errors; typed error objects; one **error boundary per remote mount**.
- No `console.log` in committed code — use the structured logger; report to Sentry with release + remote tags.

## 7. Lint / format
- ESLint flat config + `typescript-eslint` + Prettier; shared in `packages/config`.
- CI fails on lint or type errors. `eslint-plugin-boundaries` + i18n no-literal rule enabled.

## 8. Git & PR
- **Conventional Commits** (`feat:`, `fix:`, `chore:`…), trunk-based with short-lived branches.
- PR checklist: tests added, **coverage ≥ 90%**, a11y (axe) checked, i18n keys added (no literals), no secrets, docs updated, preview deploy green.
